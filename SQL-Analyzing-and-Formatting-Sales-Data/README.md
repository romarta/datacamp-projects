# Super Store Data Cleaning and Analysis

SQL project focused on cleaning and analyzing sales data from a hypothetical Super Store.

## Objective

Analyze Super Store data to:

- identify the top five products in each category based on total sales
- calculate total sales and total profit for each product
- rank products within each category using window functions
- detect orders with missing quantity values
- estimate missing quantities using product pricing information based on available order data

Sales and profit values are aggregated and rounded to two decimal places, while missing quantity values are estimated and rounded to whole numbers.

## Files
- solution.sql - final SQL queries
