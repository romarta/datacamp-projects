# GoodThought NGO Analysis

SQL project analyzing donations and project impact for GoodThought NGO
across different regions and donor types.

## Objective

Analyze GoodThought projects to:

- identify the top five assignments by total donation value and donor type
- find the highest-impact assignment in each region
- count the total number of donations received by each selected assignment

Donation amounts are aggregated and rounded to two decimal places, while regional project rankings are determined using window functions.

## Files
- solution.sql - final SQL queries
- notebook.ipynb - project notebook with the solutions
